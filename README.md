# The strategy vs you

Upload a smallcase timeline export and Zerodha statements; get a deterministic
answer to "how did the strategy perform, how did MY implementation perform,
and why do they differ" — plus a question box that explains the computed
numbers and calculates nothing itself.

**Live app:** _(paste your streamlit.app URL here once deployed)_

## What it does

The calculation engine (`smallcase_attribution/`) reconstructs what the
smallcase model would have traded, attributes your actual Zerodha trades to it,
and decomposes the difference into implementation price effects and quantity
deviations — with an exact per-leg reconciliation identity. Costs, dividends
and tax are separate layers. The engine applies no tax rates; it emits the tax
base and leaves treatment to interpretation.

Full methodology: see the engine's own README in the project repo.

## Deploy on Streamlit Community Cloud (free)

1. Push this folder to a **public** GitHub repo (`app.py` at the repo root).
2. Go to share.streamlit.io, sign in with GitHub, click **Create app**.
3. Pick the repo, branch `main`, main file `app.py`.
4. Open **Advanced settings → Secrets** and paste:

       GEMINI_API_KEY = "your-key-from-aistudio.google.com"

   Optional: `GEMINI_MODEL = "gemini-2.5-flash"`. Without a key everything
   works except the question box.
5. Click **Deploy**. First build takes a few minutes.

Free tier: ~1 GB RAM, apps sleep after 12 quiet hours and wake on the next
visit, unlimited public apps.

## Run locally

    pip install -r requirements.txt
    streamlit run app.py

For the question box locally, create `.streamlit/secrets.toml` with the same
`GEMINI_API_KEY` line (and add `.streamlit/` to `.gitignore`).

## Notes

- **Never commit your own statements.** The repo should contain only `app.py`,
  `requirements.txt`, `smallcase_attribution/`, `demo_data/` and `make_demo.py`.
  Real tradebooks, P&L files and price caches stay on your machine and are
  uploaded through the app at runtime.
- **EOD prices:** the gap attribution needs `prices_cache.csv`, generated once
  by `fetch_prices.py` in the engine repo. NSE blocks datacenter IPs, so the
  app asks the user to upload it rather than fetching server-side. Everything
  that doesn't need prices still works without it.
- **Demo mode** is entirely fictional data — six invented companies (Albus,
  Bellatrix, Cedery, Draco, Hedwig, Luna) generated by `make_demo.py` using the
  same methodology the engine verifies. No real portfolio is exposed.
